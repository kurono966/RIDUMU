タイミング

最初は4拍のリムショットで準備し、HAT → DRUMS → BASS → LEADを続けて入力。パート間の開始操作を省き、戦闘後も自動で続きます。停止ボタン／Escで中断（入力中のパートは録り直し）。

2小節の8分音符を自動で作り、HATの入力を省略してDRUMSから演奏します。通常入力・連続入力の両方で使えます。

生演奏が基本。再生時のタイミングを補正できます。

遊び方と操作
  1. H / SPACEでハイハットを刻む。
  2. A / Lでドラムを重ねて攻撃を準備。
  3. ベースを長押しして盾を作る。
  4. リードで支援し、全パートで攻撃。

タッチでも演奏できます。紫の帯は毒。詳しい効果は結果の「解析・内訳」へ。

演奏の解析と内訳

今回効いたもの 最大3つ

    SOUND / 音色をつくる

    BASS / LEADは各1音、後から押した音を優先します。音を鳴らしながら調整できます。パッドの左右でCutoff、上下で音量。パッドから離れると設定したCutoffと音量100%に戻ります。

    TIMBRE / 音色の属性配分

    A：立ち上がり → D：減衰 → S：保持音量 → R：余韻

    炎：明るく鋭い波形＋速い立ち上がり → 攻撃↑・盾↓
    水：丸い波形＋長い余韻 → 湿潤で敵攻撃↓・攻撃↓
    風：開いたフィルター＋短い保持 → 命中↑・盾↓
    土：暗い音＋厚い保持 → 盾↑・攻撃／命中↓

    リズム由来の属性はそのまま。音色の攻撃・命中は各パート1/2、盾はBass全量とLead半量で反映。水属性の湿潤は今回の敵反撃のみ、合計12%まで。配分は合計100%、無音には効果なし。

    DEV / 補正後の評価

    開発用の比較計算です。戦闘・録音・発見メモには反映しません。通常評価は元の入力を保持し、補正後評価は発音時刻を各解析の基準にします。
