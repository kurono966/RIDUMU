設定と記録

タイミング

最初は4拍のリムショットで準備し、HAT → DRUMS → BASS → LEADを続けて入力。パート間の開始操作を省き、戦闘後も自動で続きます。停止ボタン／Escで中断（入力中のパートは録り直し）。

2小節の8分音符を自動で作り、HATの入力を省略してDRUMSから演奏します。通常入力・連続入力の両方で使えます。

生演奏が基本。再生時のタイミングを補正できます。

音域と音色

2音：反復と安定 / 4音：動きと安定 / 7音：跳躍も狙える / 9音：上のC・Dまで広がる。音数そのものに倍率はありません。

元の音符・音色・戦闘計算は変えません。演奏中の表示は途中評価です。

演奏の表示

画面全体にゲームを表示します。終了はこのボタンまたはEscキーから。

キーボードだけで演奏する場合はパッドを隠せます。

記録と発見
遊び方と操作
  1. H / SPACEでハイハットを刻む。
  2. A / Lでドラムを重ねて攻撃を準備。
  3. ベースを長押しして盾を作る。
  4. リードで支援し、全パートで攻撃。

タッチでも演奏できます。紫の帯は毒。詳しい効果は結果の「解析・内訳」へ。

↑ 上昇 · ↓ 下降 · ＝ 反復 · ↯ 跳躍。項目を選ぶと評価した音符を強調します。命中は確率ではなくダメージ効率です。評価は16分枠ごとの最後の音（最大32音）を使い、間隔の比率で判断します。

    SOUND / 音色をつくる

    BASS / LEADは各1音、後から押した音を優先します。音を鳴らしながら調整できます。パッドの左右でCutoff、上下で音量。パッドから離れると設定したCutoffと音量100%に戻ります。

    TIMBRE / 音色の個性

    A：立ち上がり → D：減衰 → S：保持音量 → R：余韻

    音色の波形・フィルターは自由に選べます。短音を刻むスタイルと長音をつなげるスタイルに小さなトレードオフがあります。敵の弱点に合わせて音色を変える必要はありません。

    DEV / 補正後の評価

    開発用の比較計算です。戦闘・録音・発見メモには反映しません。通常評価は元の入力を保持し、補正後評価は発音時刻を各解析の基準にします。

    属性判定スコア表示割合

    割合は表示用です。戦闘は元のスコアで判定します。少ない入力では傾向が大きく変わります。

    ▰ 土

    キック中心で、間を空ける。規則的な間隔や、間を置いて打つキックも土につながります。

    ≋ 風

    キックとスネアを交互に刻む。交互演奏に加え、スネアの割合、細かい刻み、跳ねるグルーヴも関係します。

    ▲ 火

    後半に向かって音を増やす。短い連打や密度の集中も火につながります。

    ϟ 雷

    裏拍やシンコペーションを使う。間隔の変化や再現された揺れも雷につながります。
