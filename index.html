タイミング

最初は4拍のリムショットで準備し、HAT → DRUMS → BASS → LEADを続けて入力。パート間の開始操作を省き、戦闘後も自動で続きます。停止ボタン／Escで中断（入力中のパートは録り直し）。

2小節の8分音符を自動で作り、HATの入力を省略してDRUMSから演奏します。通常入力・連続入力の両方で使えます。

生演奏が基本。再生時のタイミングを補正できます。

音域と音色

2音：反復と安定 / 4音：動きと安定 / 7音：跳躍も狙える / 9音：上のC・Dまで広がる。音数そのものに倍率はありません。

ドラムはパートごとに音色を選び、試聴できます。選択は次回の起動時にも引き継がれます。

元の音符・音色・戦闘計算は変えません。演奏中の表示は途中評価です。

遊び方と操作

  2. A / Lでドラムを重ねて攻撃を準備。
  3. ベースを長押しして盾を作る。

タッチでも演奏できます。紫の帯は毒。詳しい効果は結果の「解析・内訳」へ。

演奏の解析と内訳

正確さ：補正前のDrumsとHatを評価。タイトは拍への一致、各種ノリは別小節でのズレ方の再現を測ります。100%は平均誤差0、16分音符の20%の誤差で0%。入力・反復が不足すると判定待ち。 Bass・Lead：自身のリズム35%＋他パートとの間隔の再現65%。揃える・一定の間隔でずらす・同じ跳ねや揺れを繰り返す演奏を評価。盾・支援効果は精度に応じて最大±20%。音が少ない場合は補正なし。BassはHat・Drums、LeadはHat・Drums・Bassとの関係を評価します。

    SOUND / 音色をつくる

    BASS / LEADは各1音、後から押した音を優先します。音を鳴らしながら調整できます。パッドの左右でCutoff、上下で音量。パッドから離れると設定したCutoffと音量100%に戻ります。

    音色と戦闘の関係

    AttackとRelease、演奏した音の長さから、攻撃・盾の小さな補正が決まります。

    演奏例攻撃への寄与Bass盾生成
    補正に関わる項目・計算ルール

    速いAttackで短く刻むと攻撃寄り、長音とReleaseは盾寄り。両者には小さなトレードオフがあります。OSC・Sub・Detune・Filter・LFO・Driveは音の質感を作る項目です。属性・敵の弱点・命中率への直接の倍率はありません。

    攻撃はBass・Leadを各1/2で合算。盾はBassの生成量に適用し、LeadはBass元盾の増減率を1/2で支援します。丸め処理があります。盾容量は通常90、ローグライトでは盾機材の成長分だけ増えます。

    TIMBRE / 音色の個性

    A：立ち上がり → D：減衰 → S：保持音量 → R：余韻

    音色の波形・フィルターは自由に選べます。短音を刻むスタイルと長音をつなげるスタイルに小さなトレードオフがあります。敵の弱点に合わせて音色を変える必要はありません。

    DEV / 敵選択と評価

    Drumsの演奏開始前に、3パートをまとめて自動入力できます。最大は曲頭のKick、低音の支え、旋律の応答と着地を持つ2小節の候補から、現在の敵に対する最高値を探索します。有効な敵にはレイドバック／ドランクを成立させます（理論上限ではありません）。最小は無音で0ダメージです。音色・エフェクトによって実際のダメージは変化します。

    任意の敵と戦う

    HPを全回復し、録音と戦闘状態をリセットして選んだ敵の演奏開始前に移動します。ローグライトからは通常戦に切り替わります。

    属性判定スコア表示割合

    割合は表示用です。戦闘は元のスコアで判定します。少ない入力では傾向が大きく変わります。

    ▰ 土

    キック中心で、間を空ける。規則的な間隔や、間を置いて打つキックも土につながります。

    ≋ 風

    キックとスネアを交互に刻む。交互演奏に加え、スネアの割合、細かい刻み、跳ねるグルーヴも関係します。

    ▲ 火

    後半に向かって音を増やす。短い連打や密度の集中も火につながります。

    ϟ 雷

    裏拍やシンコペーションを使う。間隔の変化や再現された揺れも雷につながります。
