# RIDUMU

`index.html` をブラウザで開くと遊べます。インストール、サーバー、外部API、ネット接続は不要です。

「演奏開始」後、120 BPMのリムショット4拍（1小節・2秒）でカウントイン。その次の1拍目から4秒間、A＝Kick / L＝Snare、または画面のパッドで自由に演奏します。演奏中は四分音符のハイハットがテンポを刻みます。カウントインの最後のリムショット（4拍目・開始500ms前）から入力を受け付けます。開始前の音は解析上は先頭に配置し、再生は元の入力間隔を保持します。それ以前のカウントイン入力やガイド音は解析に含みません。音OFFはガイド音も消音します。3種類の敵とのターン制戦闘。撃破後は次の敵へ進み、HPが28回復します。結果欄から直前の演奏を元のタイミングで再生できます。開始前のパッドは音の試奏ができます。

スペースキーでも演奏開始・次の敵へ進む・再挑戦ができます。演奏中の長押しでは再スタートしません。各敵のターンごとに、ドラム → ベース（A=C2 / L=G2）→ シンセリード（A=C4 / L=E♭4）を3ターン周期で繰り返します。入力は2種類のまま、パッドに現在の楽器を表示します。音色はWeb Audioで合成し、自動攻撃再生・手動再生には録音時の楽器を使用します。低音側／高音側を従来のKick／Snareに対応させてリズム解析します。

演奏したパートは保存され、次のターンの伴奏として鳴ります。ドラム → ドラム＋ベース → ドラム＋ベース＋リードと重なり、攻撃時の自動再生と手動試聴でも全パートを再生します。ドラムの番に戻ると、カウントイン開始時に全パートをリセットし、再びドラムだけから重ね直します。次の敵もドラムから始まるためリセットされます。無入力ならそのパートは保存しません。保存された伴奏は解析・ダメージには加算しません。開始前の先取りも共通の小節位置で再生し、伴奏は控えめな音量にしています。

## 実装

- `rhythm.js`：入力 → 特徴量 → 攻撃。120 BPM / 16分音符の125msグリッドは解析・結果表示だけに使用。発音とリプレイは生の入力時刻を保持します。
- 回数、密度、平均間隔、間隔の規則性、交互性、1拍パターンの反復、前後半密度、空白、連打、裏拍、シンコペーション、溜め後Kickを取得。4属性の全スコアを結果オブジェクトに保持します。
- 手数と一発の威力、安定性と属性効果にトレードオフがあります。土は反撃軽減、風は回避、火は追加燃焼、雷は行動阻害。石・飛行・機械で相性が異なります。
- `game.js`：戦闘進行、Web Audioによる合成音、原時刻リプレイ、リアルタイム表示。
- 同時押しを許可。キー長押しのOSリピートは除外。無入力でもターンは進みます。
- 演奏後は入力リズムを自動再生し、実際のノート時刻に解析済みの打撃を割り当ててHPを減らします。再生中はタイムラインのカーソルとパッドが動き、攻撃時の再生にも四分音符のハイハットが8拍入り、終了後に敵が反撃します。手動の「リズムを再生」は試聴のみで、追加ダメージは発生しません。

検証：`node --test rhythm.test.cjs input.test.cjs`。命中・ダメージ変動は乱数を使用します。
